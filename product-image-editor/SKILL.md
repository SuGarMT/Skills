# Product Image Editor — 产品原图编辑

根据产品纯图（参考基准）修改产品原图/场景图，修复产品一致性问题，确保生成的图片满足商业级别质量要求。

## 输入

用户提供 **2 张图片**：
1. **产品原图**（product_original）：产品在具体环境/场景中的图片，这是需要被修改的目标图
2. **产品纯图/海报图**（product_reference）：产品纯背景图或产品海报图，作为产品外观的参考基准

用户同时提供**修改要求**：描述需要对产品原图进行的具体修改。

## 输出

修改后的产品原图，保存到**用户指定的路径**。如果用户未指定路径，主动询问保存位置。

## 核心约束：产品原图限制条件

以下约束定义产品原图**图片本身**必须满足的条件。

### 1. 产品外观一致性

产品纯图/海报图中的商品是**唯一外观基准**，产品原图中的商品必须与之完全一致：

- 产品轮廓、比例、关键结构与参考图一致
- 材质色彩、配色方案与参考图匹配
- 标签的位置、颜色、图案与参考图相同
- 盖体、泵头、喷头等功能部件的形状和连接方式与参考图一致
- 可见内容物的颜色、装填量与参考图一致（重力分布可按新姿态调整）

### 2. 姿态与摆放

- 产品原图的视角/姿态必须与参考图**完全不同**，选择一个明显区分的观察角度。
- 如果产品是**斜放或倾斜**，必须符合物理真实性：产品必须靠在画面中可见的、尺度合理的物体上，有实际接触和支撑关系，**不能凭空倾斜或悬浮**。
- 盖体正常盖合，泵头/喷头/滴管等功能部件完整安装，**不开盖、不拆卸、不挤出内容物**。

### 3. 环境与构图

- 画面中有一个与商品用途相关的**具体环境**，不是纯色空背景。
- 画面具备**前景、中景、后景**三个层次，通过环境元素、材质对比、自然投影与景深形成丰富空间感。
- 商品在画面中清楚突出，背景空间充分展开。
- 陪衬物不遮挡商品标签或关键轮廓。
- 画面中**不出现其他同类商品**。
- 画面中**不出现海报版面或广告文字**。

### 4. 物理真实性（重力与液面）

透明容器内的内容物必须遵守物理定律：

| 内容物类型 | 重力规则 |
|---|---|
| 可流动液体 | 按重力向低处重新分布，自由液面与重力方向垂直。正常水平摄影时液面保持水平，**不跟随瓶身倾斜**。气相空间在高处，装填量及密封关系保持，不悬浮或泄漏。 |
| 粉末、颗粒 | 向容器低侧沉积，自然堆积，可形成坡面。不机械保持纯图中的分布，不要求像液体一样形成绝对水平平面。保持实际内容物种类与装填量，不悬浮、不穿透瓶壁或无故漏出。 |
| 不可见/装满/不确定物态 | 不虚构液面、粉末或内部结构。 |

### 5. 商品状态

- 商品干净、完整、无破损，无明显脏污、缺失部件、损坏或异常结构。
- 保持参考图中的闭合与完整安装状态。
- 复古风格可保留，但不能表现为脏破。
- 正常材质纹理不等于脏污；自然物特征（岩石裂隙、树皮纹理等）不视为商品破损。

## 通用质量标准

### 尺寸与画质
- 图片宽度、高度分别 **≥ 2048 像素**
- 宽高比在 **1/3 至 3** 之间
- 美学程度高，图像清晰，结构/轮廓/材质可辨认
- 内容丰富饱满，不空洞单一
- 不通过简单放大低质量图片替代画质要求

### 禁止项
- ❌ 水印、马赛克、明显生成错误、严重畸形
- ❌ 拼接图、拼图式分格画面、黑白照、纯色空背景
- ❌ 人脸
- ❌ 敏感信息
- ❌ 过度中国风（以海外商业设计为主）

### 品牌与文字
- 公共背景**不新增真实品牌名或真实品牌 Logo**
- 商品自身已有的标签、图案、品牌名按参考图保留——有则不丢，没有则不新增
- 图片中的文字仅使用**英文**，拼写正确、含义明确、字母完整清晰、无乱码
- 文字含义与商品高度相关
- 不编造商品参数、功效或认证
- 商品固有文字与图案按参考图保留，不清除、不改写、不伪造

## 工作流程

### Step 1：分析输入
1. 接收用户的 2 张图片和修改要求。
2. 观察参考图，提取产品外观基准：轮廓、比例、颜色、材质、标签、图案、部件、可见内容物。
3. 观察产品原图，识别当前场景、姿态、环境。
4. 对比两张图，识别需要修复的一致性问题。

### Step 2：生成修改后图片
1. 使用 `generate_image` 工具或构建完整提示词供用户使用。
2. 将参考图传入，确保产品一致性。

### Step 3：质量检查
对照以下清单逐项检查：
- [ ] 产品外观与参考图一致（轮廓、比例、颜色、材质、标签、部件）
- [ ] 视角与参考图明显不同
- [ ] 斜放/倾斜有实际物理支撑，无悬浮
- [ ] 物理真实性（液面水平、粉末沉积、重力方向正确）
- [ ] 环境层次丰富（前/中/后景分明，陪衬不遮挡）
- [ ] 商品闭合完整，无开盖/拆卸/出料
- [ ] 图片质量达标（≥2048px，无水印/畸形/乱码）
- [ ] 文字英文、拼写正确、含义相关
- [ ] 无人脸、无敏感信息、无真实品牌新增

### Step 4：保存与输出
1. 将修改后的图片保存到用户指定的路径。
2. 向用户说明修改内容和一致性修复点。
3. 如有不满足的约束，主动告知并提供修改建议。
